# 2D Platformer

A 2D action platformer with a three-level campaign of tall, multi-floor rooms, plus a main menu, pause menu and loading flow.

Made with Unity 6 (6000.3.9f1) and C#.

## Features

- Player movement with double jump, wall jump, coyote time and drop-through platforms
- Melee and ranged enemies, plus arrow traps, fire traps and Spikeheads
- Health system with a health bar and health pickups
- Checkpoints and respawning
- Sound effects, music and volume settings

## How to play

Open `Assets/Scenes/Main Menu.unity` in Unity and press Play.

| Action | Key |
| --- | --- |
| Move | A / D or arrow keys |
| Jump / double jump / wall jump | Space |
| Drop through platform | S or Down |
| Shoot | Left mouse |
| Pause | Escape |
